# Node のインストール

Node.jsとnpmをダウンロード:

Node.jsの公式ウェブサイト（https://nodejs.org/ ）にアクセスし、最新のLTS（Long Term Support）バージョンをダウンロードします。

インストールが完了したら、ターミナルで以下のコマンドを実行して、Node.jsとnpmのバージョンを確認します。

```
node -v
npm -v
```

# OBS の設定

## mac

- エンコーダー：Apple VT H.264 ハードウェアエンコーダ
- 出力を里スケールする：無効
- ビットレート: 6,000 ～ 8,000 kbps
- プロファイル: high
- キーフレーム間隔: 2.0s
- レート制御：CBR

## 安定化

| 優先度,対策項目,推奨設定                   |
|---------------------------------|
| 高,ビットレート制限,"2,500 ～ 3,500 kbps" |
| 高,フレームレート,30 fps                |
| 中,動的ビットレート,有効にする                |
| 中,接続方法,USBケーブルで直接接続             |
| 低,解像度,720p (1280x720)           |
